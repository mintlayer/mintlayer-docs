Mintlayer comes with several wallets, each implemented for different purposes.

## 2.1 Mojito
[![mojito Wallet](/img/whitepaper/wallets.webp)](https://www.mintlayer.org/en/mojito-wallet)

Mojito is a Bitcoin wallet that also supports the Mintlayer network. It is available for Android, Apple iPhone, as well as a browser extension for Chrome, Firefox, and Edge.

As a Bitcoin-first wallet, Mojito supports HD Wallets and the Lightning Network for fast payments.

Currently, the platform supports BTC and ML tokens. In the near future, it will expand to support any token issued on the Mintlayer Network, as well as the ability to delegate ML tokens to staking pools.


## 2.2 The full node : node-gui

Node GUI is a full node GUI that can even be used to run a staking pool from a desktop computer. 

[![node-gui-screenshot.png](/img/whitepaper/node-gui-screenshot.webp)](/img/whitepaper/node-gui-screenshot.webp)


## 2.3 Command Line Wallet: wallet-cli

The Wallet CLI is an interactive, command-line, full-featured wallet for Mintlayer. It is the ideal choice for professional node operators who are proficient in using the command line.

[![wallet-cli-screenshot.png](/img/whitepaper/wallet-cli-screenshot.webp)](/img/whitepaper/wallet-cli-screenshot.webp)

## 2.4 Programmable node: wallet-rpc

The Wallet RPC is designed for developers. Once operational, it exposes a port to which developers can connect, enabling them to send commands in a programmatic manner. This feature is ideal for exchanges, marketplaces, e-shops, and similar platforms.
