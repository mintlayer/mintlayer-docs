> **Legacy spelling:** this command was previously spelled `transaction-list-pending`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

List the pending transactions that can be abandoned.

## Usage

```
transaction list-pending
```

## Related

- [`transaction abandon`](transaction-abandon-command-guide.md): Abandon a pending transaction.
- [`transaction list-by-address`](transaction-list-by-address-command-guide.md): List confirmed transactions.
