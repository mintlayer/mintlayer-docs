> **Legacy spelling:** this command was previously spelled `standalone-address-details`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Show standalone address details.

## Usage

```
address standalone details <ADDRESS>
```

## Arguments

- **`<ADDRESS>`**: The standalone address to inspect.
