> **Legacy spelling:** this command was previously spelled `standalone-address-show`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Show added standalone addresses with their labels.

## Usage

```
address standalone list
```

## Notes

This command is available in cold wallet mode (`--cold-wallet`).
