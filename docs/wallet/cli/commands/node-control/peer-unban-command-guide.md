> **Legacy spelling:** this command was previously spelled `node-unban-peer-address`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Unban an address in the node.

## Usage

```
peer unban <ADDRESS>
```

## Arguments

- **`<ADDRESS>`**: The IP address to unban.

## Related

- [`peer ban`](peer-ban-command-guide.md): Ban an address.
- [`peer banned`](peer-banned-command-guide.md): List banned addresses.
