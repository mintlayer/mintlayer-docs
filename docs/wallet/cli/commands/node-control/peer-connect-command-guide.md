> **Legacy spelling:** this command was previously spelled `node-connect-to-peer`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Connect to a remote peer in the node.

## Usage

```
peer connect <ADDRESS>
```

## Arguments

- **`<ADDRESS>`**: The address of the peer to connect to (IP address and port).

## Examples

```
peer connect 1.2.3.4:3031
```

## Related

- [`peer disconnect`](peer-disconnect-command-guide.md): Disconnect a peer.
- [`peer list`](peer-list-command-guide.md): List currently connected peers.
