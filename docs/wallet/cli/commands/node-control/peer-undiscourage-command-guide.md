> **Legacy spelling:** this command was previously spelled `node-undiscourage-peer-address`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Undiscourage an address in the node.

## Usage

```
peer undiscourage <ADDRESS>
```

## Arguments

- **`<ADDRESS>`**: The IP address to undiscourage.

## Related

- [`peer discouraged`](peer-discouraged-command-guide.md): List discouraged peers.
- [`peer ban`](peer-ban-command-guide.md): Ban an address.
