> **Legacy spelling:** this command was previously spelled `node-list-reserved-peers`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

List reserved peers in the node.

Reserved peers are always kept connected to, regardless of normal peer management.

## Usage

```
peer reserved list
```

## Related

- [`peer reserved add`](peer-reserved-add-command-guide.md): Add a reserved peer.
- [`peer reserved remove`](peer-reserved-remove-command-guide.md): Remove a reserved peer.
