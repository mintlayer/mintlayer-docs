> **Legacy spelling:** this command was previously spelled `node-remove-reserved-peer`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Remove a reserved peer in the node.

## Usage

```
peer reserved remove <ADDRESS>
```

## Arguments

- **`<ADDRESS>`**: The address of the reserved peer to remove.

## Related

- [`peer reserved add`](peer-reserved-add-command-guide.md): Add a reserved peer.
- [`peer reserved list`](peer-reserved-list-command-guide.md): List all reserved peers.
