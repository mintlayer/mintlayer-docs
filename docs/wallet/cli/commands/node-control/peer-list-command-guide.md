> **Legacy spelling:** this command was previously spelled `node-list-connected-peers`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

List connected peers in the node.

## Usage

```
peer list
```

## Related

- [`peer count`](peer-count-command-guide.md): Get the number of connected peers.
- [`peer connect`](peer-connect-command-guide.md): Connect to a peer.
- [`peer disconnect`](peer-disconnect-command-guide.md): Disconnect a peer.
