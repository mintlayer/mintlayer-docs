> **Legacy spelling:** this command was previously spelled `node-get-block`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Get a block by its id, represented as hex encoded bytes.

## Usage

```
node block <ID>
```

## Arguments

- **`<ID>`**: The block id to retrieve.

## Related

- [`node best-block --id`](node-best-block-command-guide.md): Get the current best block id.
- [`node block-id`](node-block-id-command-guide.md): Get the block id at a given height.
