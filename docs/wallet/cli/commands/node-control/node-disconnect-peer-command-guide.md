Disconnect a remote peer in the node.

## Usage

```
node-disconnect-peer <PEER_ID>
```

## Arguments

- **`<PEER_ID>`**: The ID of the peer to disconnect. Use `node-list-connected-peers` to find peer IDs.

## Related

- [`node-connect-to-peer`](node-connect-to-peer-command-guide.md): Connect to a peer.
- [`node-list-connected-peers`](node-list-connected-peers-command-guide.md): List currently connected peers.
