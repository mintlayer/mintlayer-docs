> **Legacy spelling:** this command was previously spelled `node-disconnect-peer`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Disconnect a remote peer in the node.

## Usage

```
peer disconnect <PEER_ID>
```

## Arguments

- **`<PEER_ID>`**: The ID of the peer to disconnect. Use `peer list` to find peer IDs.

## Related

- [`peer connect`](peer-connect-command-guide.md): Connect to a peer.
- [`peer list`](peer-list-command-guide.md): List currently connected peers.
