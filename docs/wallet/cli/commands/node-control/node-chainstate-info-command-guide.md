> **Legacy spelling:** this command was previously spelled `node-chainstate-info`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Returns the current node's chainstate information (block height and more).

## Usage

```
node chainstate-info
```

## Related

- [`node best-block --id`](node-best-block-command-guide.md): Returns the current best block id.
- [`node best-block --height`](node-best-block-command-guide.md): Returns the current best block height.
