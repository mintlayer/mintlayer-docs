> **Legacy spelling:** this command was previously spelled `address-new`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Generate a new unused address.

## Usage

```
address new
```

## Notes

Each call generates a new address derived from the wallet's key chain. Previously generated addresses remain valid, you can generate as many as needed. Use `address list` to see all existing addresses and their usage state.
