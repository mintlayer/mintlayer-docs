Creates a QR code of the provided address.

## Usage

```
address-qrcode <ADDRESS>
```

## Arguments

- **`<ADDRESS>`**: The address to encode as a QR code.

## Examples

```
address-qrcode mtc1qyerxzjxfpz9zy2n7dfs73yvhglyfy5f8hkmmfu0
```

## Notes

QR code output can be disabled globally with the `--no-qr` startup option.
