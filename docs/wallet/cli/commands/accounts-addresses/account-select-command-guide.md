> **Legacy spelling:** this command was previously spelled `account-select`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Switch to a given wallet account.

## Usage

```
account select <ACCOUNT_INDEX>
```

## Arguments

- **`<ACCOUNT_INDEX>`**: The index of the account to switch to.

## Examples

```
# Switch to account 0 (the default account)
account select 0

# Switch to account 1
account select 1
```
