Reveal the public key behind the specified "public key hash" address as a hex encoded string.

## Usage

```
address-reveal-public-key-as-hex <PUBLIC_KEY_HASH>
```

## Arguments

- **`<PUBLIC_KEY_HASH>`**: A standard public key hash address (e.g. one returned by `address-new` or `address-show`).

## Examples

```
address-reveal-public-key-as-hex mtc1qyerxzjxfpz9zy2n7dfs73yvhglyfy5f8hkmmfu0
```
