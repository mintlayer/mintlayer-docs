> **Legacy spelling:** this command was previously spelled `delegation-list-ids`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

List delegation ids controlled by the selected account in this wallet, with their balances.

## Usage

```
delegation list
```

- [`delegation create`](delegation-create-command-guide.md): Create a new delegation.
