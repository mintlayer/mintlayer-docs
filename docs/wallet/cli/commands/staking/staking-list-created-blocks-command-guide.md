> **Legacy spelling:** this command was previously spelled `staking-list-created-block-ids`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

List the blocks created by the selected account in this wallet through staking/mining/etc.

## Usage

```
staking list-created-blocks
```

## Related

- [`staking list-pools`](staking-list-pools-command-guide.md): List pools controlled by this account.
- [`staking status`](staking-status-command-guide.md): Show current staking status.
