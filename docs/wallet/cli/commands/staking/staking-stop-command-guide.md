---
title: "staking-stop"
sidebar_position: 90
---

Stop staking, assuming there are staking pools currently staking in the selected account in this wallet.

## Usage

```
staking-stop
```

## Related

- [`staking-start`](staking-start-command-guide.md): Start staking.
- [`staking-status`](staking-status-command-guide.md): Show current staking status.
