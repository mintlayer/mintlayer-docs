> **Legacy spelling:** this command was previously spelled `staking-status`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Show the staking status for the currently selected account in this wallet.

## Usage

```
staking status
```

## Related

- [`staking start`](staking-start-command-guide.md): Start staking.
- [`staking stop`](staking-stop-command-guide.md): Stop staking.
