Obtain the balance of a staking pool.

## Usage

```
staking-pool-balance <POOL_ID>
```

## Arguments

- **`<POOL_ID>`**: The id of the pool to query.

## Related

- [`staking-list-pools`](staking-list-pools-command-guide.md): List pool ids controlled by this account.
- [`delegation-list-ids`](delegation-list-ids-command-guide.md): List delegation ids and their balances.
