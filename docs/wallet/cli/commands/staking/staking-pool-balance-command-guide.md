> **Legacy spelling:** this command was previously spelled `staking-pool-balance`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Obtain the balance of a staking pool.

## Usage

```
staking pool-balance <POOL_ID>
```

## Arguments

- **`<POOL_ID>`**: The id of the pool to query.

## Related

- [`staking list-pools`](staking-list-pools-command-guide.md): List pool ids controlled by this account.
- [`delegation list`](delegation-list-command-guide.md): List delegation ids and their balances.
