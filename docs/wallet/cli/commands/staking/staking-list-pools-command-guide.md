List ids of pools that are controlled by the selected account in this wallet.

## Usage

```
staking-list-pools
```

## Notes

This lists pools where the staking key is owned by this account. To list pools whose decommission key is owned by this account, use `staking-list-owned-pools-for-decommission`.
