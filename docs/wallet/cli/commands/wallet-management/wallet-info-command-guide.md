> **Legacy spelling:** this command was previously spelled `wallet-info`. Both spellings work, but only the nested spelling shown here appears in `help` and tab completion (v1.4.5+).

Obtain certain information about the wallet, such as the number of accounts and their names.

## Usage

```
wallet info
```

## Notes

This command is available in cold wallet mode (`--cold-wallet`).
