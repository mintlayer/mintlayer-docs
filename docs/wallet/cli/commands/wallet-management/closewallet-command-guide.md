The `closewallet` command is used to close the currently opened wallet in Mintlayer.

## Usage

```
closewallet
```

### Options

- `-h, --help`: Displays the help message for the `closewallet` command.

## Important Notes

- Ensure you have saved any necessary information or completed any transactions before closing the wallet.
- Once the wallet is closed, you will need to use the `openwallet` command to access it again.
