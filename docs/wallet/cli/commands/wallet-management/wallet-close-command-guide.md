Close the currently opened wallet file.

## Usage

```
wallet-close
```

## Notes

This command is available in cold wallet mode (`--cold-wallet`). Closing the wallet does not exit the REPL, use `exit` to quit the wallet application entirely.

## Related

- [`wallet-open`](wallet-open-command-guide.md): Open an existing wallet file.
- [`exit`](exit-command-guide.md): Exit the wallet application.
