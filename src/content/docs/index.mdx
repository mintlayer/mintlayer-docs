## What is Mintlayer?

Mintlayer is a blockchain platform built for the future of finance. It anchors consensus to Bitcoin, supports multi-token wallets, native tokenization standards (MLS-01 / MLS-02 / MLS-03), decentralized exchange primitives, and bridges to Ethereum.

## Highlights

- **Bitcoin-anchored security** — rounds and participant selection use Bitcoin block hashes as entropy.
- **Native tokenization** — MLS standards for fungible, confidential, and non-fungible assets.
- **Built-in DEX primitives** — atomic swaps, DHT multiparty matching, and Lightning interoperability.
- **Developer surfaces** — Mojito inject API, JavaScript SDK, MCP, and ERC-20 bridge.
